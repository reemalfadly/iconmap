# Third-party material in iconMap Globe

| what | source | licence |
|---|---|---|
| data/world.json (country borders, Arabic + English names) | Natural Earth 1:10m admin-0 countries, via github.com/nvkelso/natural-earth-vector | public domain (rights/natural-earth-LICENSE.md) |
| satellite imagery (cache/globe-8k.jpg, <project>/web/img/*.jpg, downloaded by prep.py, not shipped) | NASA Blue Marble, layer BlueMarble_ShadedRelief_Bathymetry, via NASA GIBS (Global Imagery Browse Services, part of NASA EOSDIS) | NASA imagery is free to use; put the GIBS acknowledgement in the video description (build.py prints it) |
| engine/fonts/Lalezar-Regular.ttf | Google Fonts, Lalezar | SIL OFL 1.1 (engine/fonts/OFL-lalezar.txt) |
| engine/fonts/IBMPlexSansArabic-SemiBold.ttf | IBM Plex Sans Arabic | SIL OFL 1.1 (engine/fonts/OFL-ibmplexsansarabic.txt) |
| engine/fonts/Poppins-ExtraBold.ttf | Google Fonts, Poppins | SIL OFL 1.1 (engine/fonts/OFL-poppins.txt) |
| sounds referenced as `LIB:` in cues.json | iconMap's own synthesised kit (assets/sfx), or the user's local SFX library | the kit is part of iconMap |
| data/rivers.json (rivers + lake centerlines) | Natural Earth 1:10m, via github.com/nvkelso/natural-earth-vector | public domain |
| engine/fonts/ArefRuqaa-Bold.ttf | Aref Ruqaa (alif-type/aref-ruqaa, Google Fonts) | SIL OFL 1.1 (engine/fonts/OFL-arefruqaa.txt) |
| engine/fonts/DMSerifDisplay-Italic.ttf | Google Fonts, DM Serif Display | SIL OFL 1.1 (engine/fonts/OFL-dmserifdisplay.txt) |
| engine/fonts/Poppins-SemiBold.ttf | Google Fonts, Poppins | SIL OFL 1.1 (engine/fonts/OFL-poppins.txt) |

The engine, scripts and story format are iconReem's own code. Nothing in this skill is copied from other map skills.
