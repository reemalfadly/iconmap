# iconMap script and ideas

ROOT = the folder two levels above this skill's base directory (`../..`).

## The 5 ideas (question 2 of the interview)
- Give exactly 5 ideas for the chosen type, one line each: a title phrased as a question or a surprising fact, plus the places that will appear. Vary them: different regions, one local or Gulf idea, one surprising, one comparison.
- Every idea must be visual on a map and checkable from official sources. Do not propose an idea whose key claim cannot be verified. Prefer angles with a paradox (a tiny country with huge weight, a river that crosses five countries, a strait everyone depends on).
- Let the user pick 1-5 or write his own.

## The script
1. List the claims the script needs. Verify each from a primary or official source that you actually read (government, statistics office, an agency such as EIA, an official atlas). Separate confirmed facts from estimates and opinions. Keep the wording neutral. Anything not verified is left out, never used in the hook.
2. Shape (about 2 words a second spoken): paradox hook in the first 2 seconds; the question out loud; one map action per clause (every place named lights up on its word); one number at a time, said as words and shown big; a one-line payoff that answers the hook.
3. Length: seconds x 2 words (a 30 s Short is about 52-60 words). Run a voice test and trim.
4. Write `script.txt` (numbers as words for the voice) and `sources.md`: for each number, the exact quoted sentence, the URL and its date, and a list of what was left out because it could not be verified. If a primary source has stopped publishing (for example a retired factbook), say so and use another one.
5. Check wording: plain Arabic, the user's dialect if he or she writes in one, no hype.

## Source habits
Read the page itself (fetch it); a search snippet is not a source. State the year each figure belongs to on screen when it matters ("2021"). Never invent a figure to fill a gap.
